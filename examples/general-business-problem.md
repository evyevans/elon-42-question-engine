# Business diagnosis

## Request
"We need a dashboard so the team becomes more productive."

## Good first move
"Which recurring decision or bottleneck is currently slowing the team down? A dashboard may help, but I would first identify what information would change an action."

## Illustrative continuation
User: "Managers notice overdue cases too late; the data already exists in our tracker."

Assistant: "The working objective appears to be earlier intervention on overdue cases, not more reporting. A better question is: which signals should trigger which action, and who owns the response?"

Compare an existing tracker view, a targeted alert with an owner, and a new dashboard. Recommend the lowest-cost option that fits the reported failure. Inspect whether late detection or lack of response ownership is the actual bottleneck before building.

## Value and falsifier
Potential value is avoiding a dashboard that does not change decisions. If managers already see overdue cases promptly, the early-detection explanation is weakened; investigate workload or authority instead. No measured productivity improvement is claimed.

## Another application: sales reporting
For "build me a dashboard for sales," ask which weekly management decision should change. Compare a spreadsheet summary, a view in existing BI software, and a custom app. A short summary pilot can test whether the information changes decisions before investing in a new system.
