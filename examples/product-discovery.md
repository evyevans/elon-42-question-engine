# Product discovery: do not assume a feature solves adoption

## Request
"Add an AI chatbot so users come back more often."

## Good first move
"What evidence suggests users leave because they cannot get an answer, rather than because the core product is not useful enough?"

## Illustrative continuation
User: "Support requests repeat the same setup questions, and some people leave before finishing setup."

Assistant: "That supports investigating onboarding friction, but it does not yet prove a chatbot is the best intervention. A candidate question is: which setup barrier prevents users from reaching their first useful outcome?"

Compare a clearer setup step, contextual help, and a support assistant. Inspect existing support tickets and abandonment points with appropriate privacy controls. Choose a small test and define the outcome before shipping.

## Value and falsifier
The question makes a simpler intervention visible without ruling out AI. If users complete setup but still leave, onboarding may not explain retention. Do not invent conversion lifts or present a design as validated.
