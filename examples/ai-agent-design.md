# Example: AI agent design

**Vague request:** "Make an agent that handles my customer emails."

**Reframe:** Which email types are repetitive and low-risk, and which need human judgment?

**Recommendation:** A fixed workflow that classifies and drafts replies for a human to approve. Add agent autonomy only for categories with a proven low error rate. Tools: read mailbox, draft only; no send permission initially. Success: percentage of drafts sent unedited, with zero unapproved sends.
