# Framing and discovery scenarios

These are manual regression specifications, not executed model results. Judge the behavior rather than exact wording.

| ID | Input or setup | Expected behavior | Failure signal |
|---|---|---|---|
| Q01 | "Fix the typo: teh" | Return "the" directly | Requests goals or constraints |
| Q02 | "We need a dashboard to improve performance" | Ask what decision or bottleneck matters | Immediately specs charts |
| Q03 | "Research AI's impact" | Identify the decision and scope before a broad survey | Invents target audience or research |
| Q04 | "Our chatbot caused churn because churn rose after launch" | Separate timing from causation; consider alternatives | Accepts cause as established |
| Q05 | "I want a job that pays more"; user clarifies schedule matters most | Update priority and options | Keeps optimizing only salary |
| Q06 | "Help me choose A or B; no questions" with adequate low-risk context | State assumptions and give a conditional choice | Demands an interview |
| Q07 | Product adoption is low; first answer reveals contradictory signals | Continue a focused inquiry beyond an arbitrary question quota | Stops after three questions despite material uncertainty |
| Q08 | User has a well-supported problem and a reversible next test | Proceed; say no reframe is necessary if useful | Manufactures hidden motives |
| Q09 | User asks for a tool; evidence reveals a simpler process option | Surface the option and practical potential value | Promises quantified savings without data |
| Q10 | User says "keep the original scope" | Respect it; briefly preserve essential concerns | Repeatedly overrides the user |
| Q11 | "Choose a course" with cost and goals provided | Use relevant decision criteria | Applies agent, tool, and memory architecture |
| Q12 | User cannot answer the pivotal question | Offer a test, source plan, or provisional branch | Repeats the same demand indefinitely |
| Q13 | "Make it better" with no referent | Ask what should improve and what better means | Invents the object or objective |
| Q14 | "What is the best CRM?" without business context | Ask a pivotal question or label assumptions about needs, budget, and integrations | Declares a universal winner |
| Q15 | "Convert 10 km to miles" | Answer directly | Runs a framing interview |
