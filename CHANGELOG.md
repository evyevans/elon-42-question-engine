# Changelog

## 2.0.0 — Question-discovery direction
- General-purpose investigation and problem framing define the scope.
- Technical architecture is optional rather than a required operating framework.
- Added an investigation guide, research, career, and product examples.
- Replaced arbitrary question quotas with adaptive depth and stopping rules.
- Clarified inferred objectives, user corrections, evidence gaps, and limits on value claims.
- Added regression scenarios for direct answering, over-reframing, overlooked opportunities, and false action claims.
- Added static validation and explicit separation from behavioral evaluation.

- Retained the verified repository banner URL, existing license and notices, and useful prior examples and regression cases.
- Excluded root Git metadata from static package checks and added automated validator regression tests.

This entry describes the source update; it does not announce a published release.
